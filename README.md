# Galya Clip Builder

Лёгкое веб-приложение на React + Vite для создания слайд-шоу из фотографий:

- загрузка и синхронизация аудио-трека с регулировкой сдвига старта;
- отдельные аудио-дорожки: основной трек, дополнительные фоновые/эффектные файлы и звук из видео на кадрах с управлением стартом;
- добавление одиночных или массовых изображений с автоматическим распределением во времени;
- авто-подхват фото и видео из локальной папки `media/media` и аудио из `media/audio` при открытии приложения в локальной сети;
- индивидуальная настройка длительности, текста и переходов (cut/fade/zoom/slide/pan);
- управление кадром без обрезки: вписывание, масштаб, смещение по осям и плавный Ken Burns‑зум для каждого слайда;
- живой предпросмотр на закреплённом таймлайне с перемоткой без аудио и с аудио;
- таймлайн подсвечивает аудиослои (основной трек, дополнительные и звук из видео) для наглядной верстки;
- выравнивание кадров по очереди и экспорт в WebM прямо в браузере.

## Запуск

```bash
npm install
npm run dev -- --host
```

Если установка пакетов недоступна (например, из-за ограничений сети),
можно использовать уже подготовленные исходники в папке `src` и настроить
менеджер пакетов под своё окружение.

### Локальная сеть и медиа-папки

- Vite запущен с `host: true`, поэтому интерфейс доступен по IP машины в локальной сети (например, `http://192.168.0.10:5173`).
- Папки `media/audio` и `media/media` создаются автоматически. Все найденные в них аудио/фото/видео подхватываются на старте: первый аудио-файл ставится как основной трек, все визуальные файлы добавляются в таймлайн подряд.
- Медиа-файлы из этих папок раздаются по путям `/media/audio/*` и `/media/media/*`, так что можно открыть приложение на другом устройстве в той же сети без ручной загрузки файлов.
